# AI Text Summarizer & Analytics API

მსუბუქი და სწრაფი RESTful მიკროსერვისი ტექსტის ავტომატური ანალიზისთვის, რომელიც აგებულია Python-სა და FastAPI-ზე.

## 🚀 ფუნქციონალი:
- სიტყვებისა და წინადადებების ზუსტი დათვლა.
- წაკითხვის სავარაუდო დროის გამოთვლა.
- ტექსტის ავტომატური შეჯამება (Summary).
- ტოპ საკვანძო სიტყვების (Keywords) ამოცნობა.

## 🛠 ტექნოლოგიები:
- **Python**
- **FastAPI**
- **Pydantic**
- **Render (Cloud Deployment)**
